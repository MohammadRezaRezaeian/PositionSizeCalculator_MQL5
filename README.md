# Upgraded Position Size Calculator (MQL5)

An enhanced version of the popular open-source MQL5 **PositionSizeCalculator**, originally developed and licensed by [www.earnforex.com](https://www.earnforex.com).

## 📌 Overview
This repository provides an upgraded version of the Position Size Calculator indicator for MetaTrader 5. It builds upon the solid foundation provided by EarnForex, adhering to the original open-source license, while introducing new features to streamline risk management and lot size calculation for traders.

## 🚀 Installation
1. Download the source files from this repository.
2. Open your MetaTrader 5 terminal.
3. Go to `File` -> `Open Data Folder`.
4. Navigate to `MQL5/Indicators/`.
5. Copy the indicator files into this folder.
6. Open MetaEditor, find the indicator, and hit **Compile** (F7).
7. Attach the indicator to any chart in MT5.
